## Definition / 定义

**EN**
Eureurgy is the engineering of elicitation: provoking ideas and insights through structured techniques — perspective shifts, disciplinary lenses, boundary challenges, counter-questioning, comparison, and meta-layer reflection. The method self-applies: elicitation must itself be elicited.

**ZH**
诱发工程术是激发思路、诱发洞察的工程化方法：视角/学科透镜/边界/反诘/对比/元层六种诱发类型。自举：诱发术也要被诱发。
